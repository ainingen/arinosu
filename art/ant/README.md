# アリのスプライト（v0.1）

白一色の素材。Unity の SpriteRenderer.color で着色する（通常＝黒、選択中＝白っぽい色）。

## ファイル

| ファイル | 中身 | ピボット（Sprite Editor で Custom 指定） |
|---|---|---|
| ant_body.png | 頭・胸・腹柄節・腹部（頭が上） | 中央 (0.5, 0.5) |
| ant_leg_front.png | 前脚（右側用） | 左端中央 (0, 0.5) |
| ant_leg_mid.png | 中脚（右側用） | 左端中央 (0, 0.5) |
| ant_leg_hind.png | 後脚（右側用） | 左端中央 (0, 0.5) |
| ant_antenna.png | 触角（右側用、くの字） | (0.018, 0.7) ＝付け根 |

左側のパーツは、右側用を flipX（または X スケール -1）して使う。
SVG は修正用の元データ（Unity には取り込まない）。

## インポート設定（全ファイル共通）

- Texture Type: Sprite (2D and UI)
- Pixels Per Unit: **1024**（胴体の縦＝1 Unity単位＝体長1cm）
- Filter Mode: Bilinear
- Compression: None（仮。Web版の容量を見て調整）
- Generate Mip Maps: オン（引いたときのちらつき防止）

## 組み立て位置（胴体の中心からの位置、Unity単位、右側）

| パーツ | 位置 (x, y) | 角度（Z回転）の目安 | 描画順 |
|---|---|---|---|
| 触角 | (0.050, 0.380) | +55°（前外向き） | 胴体より下 |
| 前脚 | (0.055, 0.160) | +40°（前向き） | 胴体より下 |
| 中脚 | (0.048, 0.060) | -5°（真横） | 胴体より下 |
| 後脚 | (0.044, -0.020) | -40°（後ろ向き） | 胴体より下 |

左側は x を負にし、角度の符号を反転する。

## 歩行（三脚歩行）

左前・右中・左後 の3本と、右前・左中・右後 の3本が交互に動く。
各脚は付け根を中心に、基準角度から ±15°【仮】前後に振る。
振る速さは移動速度に比例させる。
